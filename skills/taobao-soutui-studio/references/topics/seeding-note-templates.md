# 搜推种草笔记模板库

N5 先按当次推荐理由、成图和证据选择一个主模板。模板写的是段落职责，可调整长短、合并段落。实际商品、规格、经历和购买判断从当次资料提取。正文用自然短段，不保留模板字段名。

## 默认模板：好物发现与取舍

适用于单商品，已有可靠用途与画面，但没有真实测评。标题用「品类或场景｜一件具体好物」或「使用任务里的商品发现」。

1. **同站一边。** 从读者熟悉的取舍开场，落到一个具体的使用时刻。第一段就说清哪类人可能用得上。
2. **解释发现。** 点明商品哪个设计或特征有意思，写一个必要动作帮助理解。补一个可执行的选购判断，例如看尺寸、规格或使用条件。
3. **帮读者筛选。** 给出两种有实际区别的使用情境，说明哪一种值得考虑，哪一种可以先放一放。收在读者自己的工具清单、搭配或使用判断上。
4. **话题。** 视发布场景加入真实相关的品类、任务或人群词，数量随内容。

完整短例，假定资料已确认抽屉盒尺寸和拼放方式。

**厨房小物｜抽屉里的分格盒**

厨房抽屉不用一下子全分好。最值得先收拾的是每天都在翻的那一格，剪刀、夹子和量勺混在一起的时候尤其明显。

分格盒好选的地方，是可以先按手头的小东西排一排。买前量一下抽屉内宽和高度，再留一点拿取的余量，别光看照片里能放几个。

抽屉里主要是大件餐具的话，先留一块空位更顺手。经常找不到小夹子和量勺的，再考虑添几个分格。

## 其他模板

| 模板 | 选用条件 | 段落顺序 | 最后给读者什么 |
| --- | --- | --- | --- |
| 规格选择 | 两个以上规格或一个明确适用条件已有证据 | 容易选错的时刻 → 看哪项指标 → 用两个具体条件解释怎么选 | 一条可带走的选法 |
| 场景搭配 | 环境与使用关系可见，商品提供的价值明确 | 一个日常时刻 → 商品摆在何处或如何配合 → 说明这样安排的好处 | 适合哪种空间或日常习惯 |
| 小麻烦与解决思路 | 有具体摩擦点，商品作用可核实 | 读者熟悉的小麻烦 → 一个有用的商品细节 → 说清使用条件 | 什么时候值得试试，什么时候可沿用已有工具 |
| 过程里的好物 | 图组有真实可解释的关键动作和可见成果 | 想完成的事 → 商品在哪一步帮上忙 → 一个可见成果 | 该不该把这个工具加入准备清单 |
| 有证据的对比 | 有真实同条件对比资料 | 为什么比 → 观察到的具体差别 → 各自适用条件 | 哪类读者应看重哪个差别 |
| 实际体验笔记 | 用户提供真实使用记录、身份与条件 | 使用背景 → 一两个具体感受及依据 → 保留实际限制 | 哪种人可以参考这段体验 |
| 工具清单 | 确有多件可说明的对象，销售范围明确 | 清单适用场景 → 每件解决什么 → 按使用频率给添置顺序 | 哪件先买、哪件可以等等 |

规格选择短例，假定商品资料已核对包的内尺寸：开头「给饭盒挑袋子，最容易漏量的是饭盒的高度。」中段把量外尺寸和预留提取空间连起来。结尾给出带单层饭盒与带叠层饭盒的两种判断。

场景搭配短例，假定收纳架尺寸与摆放条件已核实：从「水槽旁只想留常用的两样东西」开始，接到沥水、取用的位置关系，收在「台面窄可以先量深度，已经有独立沥水区则按现有习惯安排」。

## 提交前检查

写作单项试跑可直接使用现有图组、事实表和笔记观察。先写一行读者的添置或选购判断，再确定标题。默认模板的正文应能分别找到使用时刻、值得分享的设计、可执行的选法和适用边界。标题承诺须与这条判断一致；同一用途下的动作不单独扩写成步骤段。

项目内记一行：选择的模板、读者的取舍、推荐细节、适用边界和事实依据。把正文中的动作句暂时拿掉，检查读者是否仍能说出商品为什么值得考虑、自己是否需要。若只剩步骤或参数，重写开头和收尾。只有明确要求教程时才用完整步骤体；使用过程中的动作只保留为推荐证据。没有真实试用、对比或销售范围证据时选择适合现有材料的模板。交付一篇标题和正文。
