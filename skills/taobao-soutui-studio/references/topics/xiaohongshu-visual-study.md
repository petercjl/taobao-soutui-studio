# 小红书图文参考

在 N3 已核实商品事实、拟定创作方向前，按用户要求或当前画面问题使用此方法。输入为商品事实、真实参考和待解决的视觉问题。产出为可追溯的视觉决定和发布文案表达参考，分别交给 N3 方向策划和 N5 文案。

1. **推导搜索词。** 从商品的用户叫法、已核实的使用动作和成果推导搜索词。商品词用于观察如何呈现主体，任务词用于观察动作如何讲清楚，成果或类目分享词用于观察封面和图组叙事。每组搜索先写清一个学习问题。
2. **按问题选样。** 打开相关图文的封面和内页，或视频里能回答问题的片段。样本要有可观察的构图或叙事差异。按证据缺口补搜，例如只有成果画面时补搜过程词。记录实际查看范围。浏览受限或样本不足时，记录缺口，以商品资料和已有可用的视觉证据继续 N3。
3. **转成画面决定。** 在商品项目记录实际搜索词，以及每条采用证据的「来源链接与图序或时间点 → 观察 → 风格或展示逻辑 → 本方向的画面决定 → 验收问题」。风格落到景别、角度、主体安排、光色与生活质感。展示逻辑落到首图先让人看到什么、如何讲清商品与动作、后续图片如何补足细节和成果。比如将“示范片段靠近双手”转成近景俯拍，验收时检查动作是否一眼可读。
4. **进入方向与样图验收。** 对照分享主题、首图主体和图组顺序，写出方案之间的可见差异。出图后分别核对视觉表达与商品一致性。刻度、文字和标识属于商品一致性。商品事实、外观、规格、配件及实际用法以已核实的商品资料为准，商品身份参考使用本商品原图。发布素材按淘宝规则验收。

已保存且适用于当前问题的商品项目观察可复用，并标明复用来源。具体笔记、截图与样图留在商品项目。只借鉴可迁移的表达方式，具体画面由当前商品与方向决定。

## 发布文案观察

打开笔记时一并读标题和正文，记录实际阅读范围。优先比较任务分享、工具介绍或过程记录中与本商品有关的样本。分别观察标题如何把商品和生活任务联系起来、开头如何引出具体问题、正文用什么细节说清用途，以及怎样收束。只看到标题时把正文标为未观察。用「笔记链接 → 表达方法 → 本篇拟用的切入点」写入当次商品项目，N5 结合实际图组改写为一份淘宝搜推标题和正文。样本是表达依据，商品事实和效果仍由本商品资料核实。

归纳写法时，记录样本如何在一件具体事情中引出商品、解释哪个可用的细节、用什么画面或下一步结束。以自己的语言归纳，区分生活过程、参数介绍与促销式文案，选择与图组匹配的表达。
