# 小红书图文参考

本页是 N2.5「小红书定向研究与图文策划」的观察方法。带着人物、空间、光色、动作、封面及内页镜头的具体问题选样；每项观察服务设定卡或候选镜头表中的一个决定。发布文案观察交给 N5。

采集执行入口为 [xhscli交接](xhscli-handoff.md)。本页负责研究与视觉判断，CLI 的搜索工作簿、带 media 清单的笔记 JSON 及同名 .media 目录为证据来源。

1. **推导搜索词。** 从商品的用户叫法、已核实的使用动作和成果推导搜索词。商品词用于观察如何呈现主体，任务词用于观察动作如何讲清楚，成果或类目分享词用于观察封面和图组叙事。每组搜索先写清一个学习问题。
2. **按问题选样。** 通过 xhscli 搜索及 note get --download-media 导出选中笔记和素材后，按 media.files 清单打开已下载的图片或视频里能回答问题的片段。样本要有可观察的构图或叙事差异。按证据缺口补搜，例如只有成果画面时补搜过程词。记录实际查看范围。浏览受限或样本不足时，记录缺口，以商品资料和已有可用的视觉证据继续 N3。
3. **拆解整篇图组与视频。** 按原顺序记录首图和每张内页的景别、机位方位与高度、商品可见面、人物接触和场景，说明它相对前图增加什么信息。区分封面吸引、空间占位、人体尺度、使用动作和细节展示；有重复也如实记录。视频按镜头段落观察并标时间，抽帧只作为已查看片段的证据。完整图组用于判断展示逻辑，单张精选用于资产参考。
4. **提炼出镜者创作意图。** 按 [出镜者创作简报](character-creative-brief.md) 综合人物商品关系、情绪与分享状态，形成生活气质和服饰妆发感觉的建议，逐项区分作者自述、画面观察、用户选择和Agent判断。具体穿着作为观察证据，初次定妆通过整体意图开放设计，确认后记录身份特征。
5. **提炼环境创作意图。** 按 [环境创作简报](environment-creative-brief.md) 综合正文、整组画面和使用关系，回答谁在这里生活、怎样生活、如何对待自己的家及整体感觉。逐项标注观察、自述、用户指定或Agent判断。环境生图的交接采用生活方式和氛围短段，家具细节留作证据；参考以整体气质和生活方式的相容性选择。
6. **转成画面决定。** 在商品项目记录实际搜索词，以及每条采用证据的「来源链接与图序或时间点 → 观察 → 风格或展示逻辑 → 本方向的画面决定 → 验收问题」。风格落到景别、角度、主体安排、光色与生活质感。展示逻辑落到首图先让人看到什么、如何讲清商品与动作、后续图片如何补足细节和成果。比如将“示范片段靠近双手”转成近景俯拍，验收时检查动作是否一眼可读。
7. **进入方向与样图验收。** 对照分享主题、首图主体和图组顺序，写出方案之间的可见差异。出图后分别核对视觉表达与商品一致性。刻度、文字和标识属于商品一致性。商品事实、外观、规格、配件及实际用法以已核实的商品资料为准，商品身份参考使用本商品原图。发布素材按淘宝规则验收。

已保存且适用于当前问题的商品项目观察可复用，并标明复用来源。具体笔记、截图与样图留在商品项目。只借鉴可迁移的表达方式，具体画面由当前商品与方向决定。

## 发布文案观察

打开笔记时一并读标题和正文，记录实际阅读范围。优先比较任务分享、工具介绍或过程记录中与本商品有关的样本。分别观察标题如何把商品和生活任务联系起来、开头如何引出具体问题、正文用什么细节说清用途，以及怎样收束。只看到标题时把正文标为未观察。用「笔记链接 → 表达方法 → 本篇拟用的切入点」写入当次商品项目，N5 结合实际图组改写为一份淘宝搜推标题和正文。样本是表达依据，商品事实和效果仍由本商品资料核实。

归纳写法时，记录样本如何在一件具体事情中引出商品、解释哪个可用的细节、用什么画面或下一步结束。以自己的语言归纳，区分生活过程、参数介绍与促销式文案，选择与图组匹配的表达。


## 原始证据与方向包

补采按笔记 ID 去重。用户未指定规模时，以至少 11 篇相关笔记为目标，按同款、同类用法和相邻视觉场景分组。每篇独立目录保留链接、正文、实际可见评论和可下载媒体，记录媒体来源、文件名、摘要及缺口。已有归档符合本次问题时复用，样本不足时明确覆盖边界。按独立笔记累计证据，区分同款证据、同类假设、商业或转载表达及画面推断。逐篇分别记录购买者、使用者和画面出镜者及各自依据（正文段落、图序或视频时间点）；身份不明记未知。将影响画面的购买者、使用者和出镜者关系写入设定卡；具体外观、动作和空间由样本观察、Agent判断、用户指定共同确定并注明理由。

选定方向后，在项目内建立可版本化的方向包。包含可生图设定卡、出镜者创作简报、环境创作简报、候选镜头表、逐镜头证据映射、由镜头推导的资产需求表、精选原图和视频抽帧、2–3 篇带批注的文案案例、证据到资产及镜头的交接表。抽帧记录笔记 ID、视频文件和时间点。每条采用项写明观察、可迁移条件、下游节点、参考职责与验收问题，标明实际垫图和仅供策划的素材。参考数量按职责选择，优先用能看清空间与光色的画面。参考图含竞争商品、脸或其他身份线索时，可截取符合职责的局部并保留原件、裁切参数与摘要。

N4 用选定图像生成方向资产，提示词注明各图职责。样图用定稿方向资产与已确认本品资产；本品尺度图用于验收。N5 用批注案例、实际成图与商品事实写原创整篇文案，迁移段落功能和选购判断。用户要求先审设定卡或方向包时，交付后停在策划审阅节点。
