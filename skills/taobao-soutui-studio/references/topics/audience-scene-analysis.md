# 小红书定向研究与图文策划

N2 商品核对之后执行。输入商品实拍、事实表、用户选择和已有原始研究素材；输出版本化可生图设定卡、候选镜头表、证据映射及资产需求表。研究同时回答“谁在什么环境中使用”和“整篇图文应该展示哪些画面、各自增加什么信息”。

## 带问题检索与决策

1. **列出决策问题。** 人物按 [出镜者创作简报](character-creative-brief.md) 明确角色、必要年龄边界、生活状态、情绪气质、表达状态、服饰妆发感觉与商品关系；环境按 [环境创作简报](environment-creative-brief.md) 明确居住者、生活状态、空间使用方式、人与家的关系和整体感觉；具体物件与布局作为研究证据，必要使用条件单列；风格提炼摄影感觉与整体气质。写清推荐理由、读者需要判断的商品问题，以及封面和内页分别需要回答的问题。
2. **以完整笔记为观察单位。** 按 [小红书观察](xiaohongshu-visual-study.md) 看首图与内页顺序，记录每张的景别、机位与高度、场景、人物动作、商品可见面及信息作用。视频按有意义的镜头段落记录，抽帧保留时间点；单帧只能支持该帧可见事实。先整体筛选，再精看能回答问题的图组和片段。至少11篇是归档覆盖目标，深读子集、实际查看范围和未解决问题分别记录；已有归档可复用，关键缺口再定向补搜。
3. **形成可生图设定。** 将样本观察、Agent创作判断、用户指定分别标注及说明理由。购买者、使用者和出镜者分别记录依据；未知身份保留未知，出镜者外观和空间由证据与明确创作决策落地。人物与空间属于同一可信生活片段。商品事实或动作安全有关键矛盾时回N2。
4. **编排候选镜头。** 读取 [推荐笔记策划](recommendation-note-planning.md)，结合首图阅读期待与内页证据安排画面。 从参考中提炼封面吸引方式、后续信息推进与有效视角，再结合本品重组。普通批次为八张独立候选；本次数量以用户明确指令为准。每张有稳定镜头ID、内容任务、推荐价值、场景、动作及接触关系、景别、机位高度与方位、商品可见信息、建议画幅、来源图序/时间点、迁移方式和验收点。每张补充可辨信息；同场景可以通过任务和取景推进。案例数量与计划张数分别记录，Agent补足的镜头明确标注创作判断。只借鉴展示方法，商品身份与性能以本品证据为准。
5. **由镜头推导资产。** 逐张列出产品、人物、环境和风格的参考需求，再合并成资产需求表。产品按全貌、相对尺度、结构、材质、标识与使用关系逐类评估新增价值，记录采用、已有证据覆盖或证据缺口；每项关联镜头ID、可用来源、制作方式与验收标准。优先选清楚原照片或裁切，需要生成整理时再交依赖处理。资产数量依需求与证据覆盖决定，遵守依赖最低合同。缺失视角不得当作真实产品证据推断；补图或调整镜头。
6. **明确参考职责。** 每个采用文件可读且摘要可查，附源笔记ID、图序或视频时间点、裁切参数、拟用节点及是否实际垫图。环境、人物、风格、动作和商品身份分别控制；其他商品不提供本品身份。研究片段和样本原文留在商品项目。

## 交付与返回

方向包包括设定卡、出镜者创作简报、环境创作简报、候选镜头表、逐镜头证据映射、资产需求表、精选原图与抽帧、带批注文案案例及研究覆盖记录。完成条件是画面设定具体、镜头任务明确、资产可据此准备、证据与创作判断可区分。

N3 从生活任务和场景组合规划九方向，选定方向细化当前镜头方案。已有方向选择时直接完成该方向，无须重选九方向。N4 将设定卡、镜头表和产品证据需求交给 product-asset-set，再制作环境、人物和风格资产。产品资产的具体图种、数量、尺寸与制作由当前依赖决定；应用提供需求与验收目标。资产确认后绑定具体参考文件与版本，编译最终提示词。若资产无法支持镜头，返回当前节点补证或修订受影响镜头并保留历史。用户要求先审方向包时，交付后停在本节点。
