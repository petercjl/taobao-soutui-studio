# 单次创作目录

在 N1 定位商品项目后，先执行 `python3 scripts/creative_run.py init --project PROJECT --item-id ID --date YYYY-MM-DD`。日期使用用户当地日期；已知方向时附 `--direction ID`。以命令返回的目录为准。编号一旦分配即固定；方向未知时，选定后更新清单的 directionId，目录名保持稳定。按 `runId` 及项目内相对 `runPath` 将运行关联到商品台账；已选方向的批次还记录 `loopRoot`。恢复使用原路径。同一会话选择多个方向时，每个方向各自初始化；共用研究证据时记录其原路径和摘要。历史运行沿原路径读取。

商品台账延用既有 `ledger/`。新采集的主图、URL、商品事实归入 `商品资料/主图/版本/`；经确认可复用的产品资产和说明归入 `商品资料/产品资产/版本/`。不覆盖既有版本。运行清单每阶段更新 stage 和 inputVersions，固定主图、产品资产、方向计划及证据版本。资产记录以商品项目为相对路径基准，同时保存来源及 SHA-256。新运行的 image_loop、image_review_html 等处理路径的命令在商品项目目录执行；传给媒体 CLI 的路径按其合同解析。

| 目录 | 写入内容 |
| --- | --- |
| 01_小红书研究 | 搜索、选样索引、研究结论；`笔记/笔记ID/` 存链接及元数据、正文.txt、图片、视频、抽帧。 |
| 02_图文策划 | 人物与场景设定卡、八镜头规划、资产需求、证据映射、文案案例批注。 |
| 03_方向资产 | 环境、人物、风格各自保存实图、提示词、回执和验收，资产清单绑定确认版本及商品级产品资产。 |
| 04_生图与验收 | `迭代台账/` 保存 image_loop 修订；`镜头/01/第01轮/` 等保存实际参数、参考顺序、提示词、预检、任务回执与成图；评分、重试与整组验收记录在台账。 |
| 05_文案过程 | 原文并读、来源与文案复核、草稿及定稿输入 TXT。 |
| 06_交付 | 整组通过后，仅含八张按镜头编号的图和一份 UTF-8 发布文案.txt。编号用于核对镜头；用户确定最终图片、顺序和封面。 |
| 07_复盘 | 迭代结束的生图复盘.html，按镜头折叠，引用每轮的实际文件。 |

八张通过且整组复核后，执行 `python3 scripts/creative_run.py finalize --run RUN --copy FINAL.txt`。脚本核对输出摘要、八个镜头和 TXT，将候选文件原样复制到交付目录，生成或核对独立的复盘 HTML，最后写入完成状态。迭代耗尽存在缺口时，以同一命令省略 --copy，归档复盘和缺口并标记 partial。任务仍待生成、恢复、验收或修正时继续相应节点。单张、双机位调试保留在对应阶段，交付指定样图。独立发布流程由用户另外启动。
