# 推荐笔记策划与验收

在 N2.5 商品事实核实后、镜头初步设计时读取，N3 复用并按所选方向细化。输入是读者需求、实物资料和相关笔记观察。输出是每个方向的推荐理由，以及选定方向的封面与八张图的分工。具体样本和决策留在当次商品项目。

1. **定推荐理由。** 为每个方向写清读者处境、值得分享的一个商品发现、支持它的证据。根据证据选择好物发现、场景分享、选择心得或过程记录。用“读者看完会记住什么”区分方向。重复的推荐理由合并或回到商品事实找新角度。
2. **拆解参考笔记。** 把标题的阅读期待、首图视觉焦点、正文补充的细节与内页证据连起来读。每条借鉴记录来源、观察、可迁移的表达及本篇决定。商品用途、规格与体验宣称使用本品资料或真实体验证据。
3. **分配画面任务。** 首图用摄影讲清主题，缩略图里商品可辨，生活场景能解释推荐理由。其余候选逐张写明要增加的可见信息。画面内容重复时换任务。先写共同的环境、光色与质感，再逐张定动作、机位与道具。提交时把实物参考、全组风格和单张任务分开写。
4. **验收后写成一篇。** 用成图复核封面与内页是否支撑原定推荐理由，同时独立核对商品保真。若画面没有兑现某个信息，修正图组或将发布文案收窄到已证实的内容。标题自然带出品类和阅读理由，正文用一个图里看不出的细节解释商品为什么值得关注。生活情境、可核实商品信息与实际成图共同约束表达。按 N5 交付一份标题和正文。
