# 单篇图片信息分工参考

本页为可选叙事框架；当前九方向与八候选主线见direction-planning.md。


先判断目标人群在什么实际情境需要商品，以及原主图尚未回答什么。事实分为可核实属性、可见外观、未核实性能、创意情境；后两项不能当事实发布。原图共同锁定商品，不做强制一对一改造。明确销售款式与套餐，环境里的配件不能被误解为随商品出售。

| 图位职责 | 决策问题 | 表现选择 |
| --- | --- | --- |
| 商品与场景 | 是什么，在哪种场合需要 | 商品完整突出，场景直接解释用途 |
| 实际使用 | 如何用、穿着或摆放 | 已有依据的动作，合理的手物与配件关系 |
| 关键决策信息 | 哪一点帮助选购 | 在清楚主体中突出真实重点；必要时用短文字，不默认局部特写 |
| 补充条件 | 还有什么环境或搭配信息 | 与前图不同的有用信息；不能为换背景虚构适用性 |
| 整体体验 | 如何形成连贯使用印象 | 商品仍突出，收束同一主题，不只留风景情绪 |

这一结构是应用策划框架，按商品调整具体景别和顺序。五张不需要五种背景；同一环境中的机位、阶段或使用关系可以形成有价值变化。每张都应能独立辨认所售商品。

服饰按衣物展示范围选择镜头，不等于每张全身人物；家居避免空间淹没商品；标品可简洁展示有来源的型号与功能。缺少数据时换成有依据的信息，不编造容量、适配范围或效果。若五张无法形成可信信息分工，返回资料节点而非填充装饰画面。

输出每图：decisionQuestion、verifiedFacts、referenceImages、scene、action、composition、lighting、textPolicy、qaFocus；整组记录theme、variant、productName、unknownFacts与styleDirection。产品名为可由图识别的核心品类名词，用于图片空间归档。
