# 商品种草图文制作

根据商品资料和用户选择的方向制作生活化种草图文，适用于淘宝天猫搜推等商品推荐场景。交付八张候选图、一篇发布文案 TXT 和单独的迭代复盘。图片、顺序和封面由用户决定，发布由独立流程处理。

给当前使用的 Agent 发送：

> 帮我安装 @petercjl/product-seeding-studio，并同步当前 Agent 的 Skill。

> 用 product-seeding-studio 为商品「商品 ID」规划种草图文方向，先给我选。

管理入口与完整 Skill 随包提供。创作需要本地 Python 和 Pillow、文件与图像检查能力，以及相应的采集、生图服务及授权。见 [安装](INSTALL.md) 和 [更新](UPDATE.md)。
